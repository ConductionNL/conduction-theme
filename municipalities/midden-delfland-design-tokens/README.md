# Midden-Delfland Design Tokens

NL Design System design tokens for Midden-Delfland.

## Usage

Install the package:

```sh
npm install @nl-design-system-unstable/midden-delfland-design-tokens
```

Apply the theme class to your root element:

```html

<html class="midden-delfland-theme">
```

## Building

```sh
npm run build
```
